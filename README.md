# OCK Rotor Free v0.4.0

Experimental reversible byte-rotor CLI for arbitrary files.

**Platform:** Linux x86_64  
**Container format:** OCKR4  
**Status:** prerelease / experimental crypto  
**Source:** not included in this public artifact

## What it does

OCK Rotor transforms arbitrary byte streams through generated byte rotors and writes an authenticated OCKR4 container.

Decode verifies the stored authentication tag before restoring output.

Supported key material:

- integer sequences
- integer key files
- dictionary + word sequences
- dictionary + word key files

Input may be:

- arbitrary files
- UTF-8 text
- stdin

Output may be:

- files
- stdout
- hexadecimal display
